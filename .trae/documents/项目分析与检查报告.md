## 安装必要依赖并建立仓库连接

### 1. 安装系统依赖
经检查，当前环境缺少运行和管理该项目所需的核心工具。我计划使用 Windows 自带的 `winget` 工具进行安装：
*   **Git:** 用于版本管理及与 GitHub 仓库 (`https://github.com/eminemlose88/fakawang`) 连接。
*   **Node.js (LTS):** 用于运行 Next.js 前端和 API 服务。
*   **Go:** 用于编译和运行 `Epusdt` 支付后端服务。

### 2. 建立仓库连接
在安装完 Git 后，我将执行以下步骤：
1.  **初始化本地仓库:** 在当前目录下执行 `git init`。
2.  **配置远程地址:** 执行 `git remote add origin https://github.com/eminemlose88/fakawang`。
3.  **代码状态检查:** 检查当前本地代码与远程仓库的差异。

### 3. 项目运行环境检查
安装完 Node.js 和 Go 后，我将：
1.  **安装前端依赖:** 执行 `npm install`。
2.  **验证数据库连接:** 检查 Prisma 与 PostgreSQL 的连接状态。
3.  **检查 Go 服务:** 验证 `Epusdt` 的依赖包是否完整。
