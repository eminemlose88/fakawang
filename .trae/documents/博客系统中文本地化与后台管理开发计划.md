### 博客系统中文本地化与后台管理开发计划 (含数据迁移)

为了实现“博客专区中文文案”及“后台增加博客”的需求，并导入之前的示例文章，我将执行以下步骤：

#### 1. 数据库升级
*   **修改 Schema**：在 `prisma/schema.prisma` 中添加 `Post` 模型，用于存储博客文章（标题、内容、摘要、标签、浏览量等）。
*   **应用变更**：执行数据库迁移，创建新表。

#### 2. 后端 API 开发
*   创建文章管理 API (`app/api/admin/posts`)，支持 CRUD 操作（增删改查）。
*   创建前台文章 API (`app/api/posts`)，用于前台展示。

#### 3. 后台管理界面
*   **文章列表**：创建 `app/admin/posts/page.tsx`，列出所有文章，支持删除和编辑入口。
*   **文章编辑器**：创建 `app/admin/posts/edit/page.tsx`（复用新建和编辑），支持标题、摘要、标签和 Markdown 内容输入。
*   **添加菜单**：在 `app/admin/layout.tsx` 中添加“文章管理”导航链接。

#### 4. 前台页面重构与汉化
*   **博客列表页** (`app/[lang]/blog/page.tsx`)：
    *   改为从数据库读取文章列表。
    *   将界面文案（如 "Tech Zone", "Read More"）全部替换为中文（"技术专区", "阅读全文" 等）。
*   **文章详情页** (`app/[lang]/blog/[slug]/page.tsx`)：
    *   改为从数据库读取文章内容。
    *   汉化相关文案（"Back to Tech Zone" -> "返回列表" 等）。

#### 5. 数据导入与清理
*   **导入示例文章**：编写脚本或直接通过 API 将之前的 "How to Securely Buy and Use AWS Accounts" 文章（翻译为中文标题和内容）插入到数据库中。
*   **清理**：删除旧的 MDX 文件系统代码 (`lib/posts.ts`, `content/blog`)。
