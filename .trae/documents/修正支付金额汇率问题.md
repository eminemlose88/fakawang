金额不一致是因为 Epusdt 默认将“CNY (人民币)”作为计价单位，然后按汇率折算成 USDT。但您的网站现在已经是**美元 (USD) 计价**，所以我们需要把汇率强制设为 1:1（即 1 USD = 1 USDT）。

订单号不一致是正常的：

* 上面的 `202512301767...` 是 **Epusdt 的交易流水号**。

* 下面的 `202512302234...` 是 **您网站的订单号**。

* 这两者是绑定的，支付成功后会自动回调。

# 解决方案：固定汇率

## 1. 修改 Epusdt 配置文件

请在 SSH 终端中执行：

```bash
nano /home/ec2-user/epusdt/epusdt-0.0.3/.env
```

找到 `forced_usdt_rate`（强制汇率）这一行。
**如果没有这一行，请在文件末尾添加：**

```ini
# 强制汇率，设为 1 表示 1 USD = 1 USDT
forced_usdt_rate=1
```

*(注意：如果之前配置的是人民币汇率，比如 7.x，请一定要改成 1)*

## 2. 重启服务

```bash
sudo systemctl restart epusdt
```

## 3. 重新下单测试

重新下单 $20.00 的商品，这次支付页面的金额应该就是 **20.00 USDT** 了。
