# AWS 部署执行计划 (确认就绪)

已收到您的 PPK 密钥文件确认。我们将立即开始执行：

1.  **资源定位**:
    *   扫描当前目录找到 `.ppk` 密钥文件。
    *   使用 AWS CLI 查询您已启动的 EC2 实例 IP 地址。

2.  **数据库准备**:
    *   创建 AWS 免费层级 RDS MySQL 实例。
    *   配置安全组规则。

3.  **构建与上传**:
    *   编译 Go 程序。
    *   尝试使用 `puttygen` 转换密钥或使用 `pscp` 上传文件（如果环境支持），否则将生成详细指令供您操作。
    *   配置并启动 Epusdt 服务。

我们开始吧。
